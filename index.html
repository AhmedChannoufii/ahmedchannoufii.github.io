PFA · Internship @ Asteelflash

Application Web de Gestion des Tests Industriels (EMS)

Industrial Web Platform developed for Asteelflash (Electronic Manufacturing Services - EMS). Implements an end-to-end 3-level quality control workflow for electronic boards, complete with strict business rejection rules, real-time hardware assignment, multi-role security (RBAC), live Chart.js analytics, and automated EPPlus Excel report generation.

🔍 Understanding the 3 Test Levels

1
Initial Test Initial Test — Checks that the electronic board's identifier (serial number) is correctly structured and valid upon registration in the system.
➔
2
Quality Control Quality Control — Physical inspection of the board to confirm it's in good condition (no visible or hardware defects) before moving forward.
➔
3
Client Test (Level 3) Client Test — Verifies that the board is correctly programmed according to the specific requirements and configuration requested by the end client.

⛔ Rejection Rule: Automatic product rejection upon 2 consecutive failures at any level. Full audit trail recorded.

🛡️ Smart System Features

  • Automatic next-test suggestion — After each successful test, the system automatically suggests the next test to perform based on the board's history.
  • Error prevention — If the user attempts an incorrect action (wrong order, invalid step), the system blocks it and stops the process immediately.
  • Smart filtering — When running a test, the operator can filter by machine and operator to quickly find the correct board/line to test.
